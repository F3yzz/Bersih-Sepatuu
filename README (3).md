# Bersih Sepatu (kode sumber)

React + Vite + TypeScript + Tailwind CSS.

```
npm install
npm run dev      # mode pengembangan
npm run build    # hasil build ada di folder dist
```

Link Google Form, WhatsApp, Instagram, dan password admin ada di bagian atas `src/App.tsx`.
Foto utama: `src/assets/bersih-sepatu-hero.webp`. Ikon tab browser: folder `public/`.
Setelah `npm run build`, salin isi `dist/` ke folder utama repository (lihat README di folder utama).
